# Tkellem English

App web pour apprendre l'anglais depuis le darija marocain (débutant, intermédiaire, expert).

## Installer sur iPhone
1. Ouvre le lien de l'app dans **Safari**.
2. Touche le bouton **Partager** (carré avec une flèche).
3. Choisis **Sur l'écran d'accueil**, puis **Ajouter**.

L'app s'ouvre ensuite en plein écran comme une vraie app et fonctionne hors ligne. La progression est enregistrée sur le téléphone.
